📋 What Happens to Your Data? (Google Play Data Safety Disclosure)

When an account deletion request is processed, our systems execute the following data hygiene protocol:

❌ Permanently Deleted
  • • User profile, name, email, profile photo
  • • Password hashes and active authentication tokens
  • • Saved Plants list and botanical notes
  • • Plant leaf images and diagnostic scan logs
  • • Geolocation coordinates (latitude & longitude)
🛡️ Retained (Legal / Anonymized)
  • • Anonymized statistical usage counts (no user identity)
  • • Web server access logs kept for cybersecurity (purged automatically after 30 days)
  • • Financial transaction invoices (only if premium purchase was made, per tax law)
